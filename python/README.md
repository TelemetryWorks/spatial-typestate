# Spatial Typestate for Python

[0.1.0 is published on PyPI](https://pypi.org/project/spatial-typestate/0.1.0/)
(checked 2026-11-09). In a virtual environment with GIL-enabled CPython >=3.11,<3.15:

```sh
python -m pip install --only-binary=:all: spatial-typestate==0.1.0
```

Wheels are x86_64 Windows and manylinux_2_28 Linux only; qualification covers
CPython 3.11/3.14 and Linux glibc 2.28/2.36 containers, not universal platforms.
No runtime Python dependencies. See the [package description](PYTHON-README.md)
and [guide](../docs/PYTHON-GUIDE.md) for source installation, limits, runtime checks
and the distinction between 0.1.0's unsigned source record and mandatory future
PyPI attestations.
