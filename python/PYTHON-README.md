# Spatial Typestate for Python

Unpublished 0.1.0 first-release candidate for the batch-oriented CPython binding.
The source candidate uses Rust core 0.1.0; the native crate also remains 0.1.0.
These independent versions do not imply publication or artifact approval.
No runtime Python dependencies. The distribution is `spatial-typestate`, the
import is `spatial_typestate`, and the extension is `spatial_typestate._native`.
See the [first-release limits and Rust migration](https://github.com/TelemetryWorks/spatial-typestate/blob/main/docs/migration-0.0.1-to-0.1.0.md).
See [the guide](https://github.com/TelemetryWorks/spatial-typestate/blob/main/docs/PYTHON-GUIDE.md)
for the workflow, copies, runtime checks and guarantees lost at the Python boundary.
