# Implemented requirements and verification

These numbered contracts describe current code, not future roadmap ideas.
Sampling is regression evidence, not proof of all numerical behavior. All row
references below are real test functions/files; CI execution is distinct from
local execution. Physical frame correctness and certification are not promised.

| ID | Current contract | Verification / status |
| --- | --- | --- |
| ST-001 | Transform<From,To,L>.apply_point accepts Point3<From,L> and returns Result<Point3<To,L>, SpatialError>; mismatched labels are compile errors. | Implemented: [basic_usage](../../tests/basic_usage.rs), [point mismatch UI](../../tests/ui/frame_mismatch.rs). |
| ST-002 | Point3, Vector3, Transform and UnitQuat implement Copy/Clone/Debug/PartialEq without requiring those traits on Frame or unit labels. Debug retains phantom labels; quaternion equality compares components, not rotation equivalence. | Implemented: bare structs/no derives in [frame_traits](../../tests/frame_traits.rs), manual implementations in [source](../../src/quaternion.rs). |
| ST-003 | UnitQuat checked construction rejects non-finite components and signed all-zero inputs, accepts every finite nonzero quaternion, and preserves finite components with approximate unit length. Relative underflow may round small components to signed zero. | Implemented: MAX/MIN_POSITIVE/subnormal/all-axis/signed-zero/NaN/Inf regressions in [quaternion_invariants](../../tests/quaternion_invariants.rs); 1,024 finite-bit-pattern samples with squared-norm error <=32*EPSILON in [quaternion_proptest](../../tests/quaternion_proptest.rs). |
| ST-004 | Quaternion components are private, const read-only getters and identity are available, and no public unchecked constructor bypasses normalization. | Implemented: const identity/getter test; reviewed [private-field UI](../../tests/ui/quaternion_components_private.rs), and [UnitQuat paired success/compile-fail doctests](../../src/quaternion.rs). Stable rustdoc checks failure, not a specific error code; both compiler versions were reviewed for E0599. |
| ST-005 | Raw matrices use row storage, column vectors, translation in column 3. apply_point ignores the bottom row and performs no perspective division; raw construction is unvalidated, while application checks finite participating values only. | Implemented/qualified: raw-layout/ignored-bottom tests in [transform_roundtrip](../../tests/transform_roundtrip.rs), [finite boundary tests](../../tests/checked_transform.rs), runnable from_matrix API example. |
| ST-006 | Checked rotation/translation construction maps p_To=R(q)*p_From+t_To using right-handed active Hamilton (x,y,z,w) algebra. R columns are From basis vectors in To; t is From origin in To. Non-finite translation is rejected. The caller asserts the physical frame relationship. | Implemented: quarter-turn and rational quaternion independent oracles plus translation rejection in [frame_workflow](../../tests/frame_workflow.rs). |
| ST-007 | apply_vector accepts Vector3<From,U>, returns Result<Vector3<To,U>, SpatialError>, and applies only R without translation. Only vector/linear-matrix values and results are checked for finiteness. | Implemented: analytic sensor vector in [frame_workflow](../../tests/frame_workflow.rs), [finite boundary tests](../../tests/checked_transform.rs), [vector mismatch UI](../../tests/ui/vector_frame_mismatch.rs). |
| ST-008 | first.then(next) composes the affine map next(first(p)), enforces the shared intermediate label, ignores both raw bottom rows, and returns Result with canonical affine bottom row on success. Participating non-finite input/output returns NonFinite. Sequential application and composition can fail at different intermediates. | Implemented: noncommuting rotations/all coordinates, raw bottom-row consistency, bounded composition property in [frame_workflow](../../tests/frame_workflow.rs); [finite boundary tests](../../tests/checked_transform.rs), [composition mismatch UI](../../tests/ui/composition_frame_mismatch.rs). |
| ST-009 | try_inverse rejects non-finite entries/output with NonFinite and finite non-rigid inputs with NonRigidTransform. Affine row, rotation row dot products and det(R)=+1 are checked at absolute 1e-10. Accepted inverse is R^T,-R^T*t, with canonical bottom row. | Implemented: scale/shear/reflection/projective/huge/NaN/Inf/overflow rejection, proper 180 acceptance and tolerance tests in [frame_workflow](../../tests/frame_workflow.rs). |
| ST-010 | Near-rigid inverse and composed mappings are approximate. Error grows with magnitude/chain length. Successful application/composition results are finite, but finite inputs can fail on overflow, and no magnitude-independent absolute roundtrip accuracy is guaranteed. Raw constructors/public values remain unvalidated. | Qualified contract: bounded property uses point range [-100,100], translation [-1000,1000], absolute 1e-9; deterministic overflow/cancellation and 1,024 finite samples in [fuzz_compat](../../tests/fuzz_compat.rs). [Numerical notes](../math_conventions.md) define limits. |
| ST-011 | SpatialError is an exhaustive concrete enum supporting Display/core Error and caller-selected boxed propagation. Library constructors/math do not allocate or invoke formatting/virtual error methods. | Implemented: messages/source/boxed ? tests in [error_reporting](../../tests/error_reporting.rs); [errors source](../../src/errors.rs) and math source review (no allocator instrumentation claim). Adding variants is an API change. |
| ST-012 | Library code denies unsafe and uses fixed-size values without I/O/global state. All runtime feature graphs have zero normal dependencies; dev tools remain separate. | Enforced compile policy in [lib.rs](../../src/lib.rs), manifest review and graph gate in [CI](../../.github/workflows/ci.yml). Not a proof about downstream applications. |
| ST-013 | Default std uses native sqrt; disabling defaults selects no_std with a private bounded Newton norm. MSRV 1.85/pin 1.91.1 library compatibility is tested separately from Rust 1.99 UI snapshots. | Implemented: 3 native-reference helper tests (boundaries/neighbors, 100,001 dense, 100,000 sampled), extreme normalization suites in both modes; [CI](../../.github/workflows/ci.yml) library checks and thumb cross-build. Cross-compilation does not prove device execution. |
| ST-014 | Quantity<U> only adds/subtracts identical unit tags. Point/transform length and vector units are required explicitly. Public raw f64 values/arithmetic remain unvalidated; no dimensional algebra or angle conversion exists. | Implemented limitation: [quantity_proptest](../../tests/quantity_proptest.rs), [unit mismatch UI](../../tests/ui/unit_mismatch.rs), [units source](../../src/units.rs), docs review. |
| ST-015 | The sensor->aircraft->world example demonstrates nontrivial rotations/target translations, sequential/composed equality within tolerance, inverse roundtrip, and translation-free vector mapping. | Implemented: [runnable example](../../examples/sensor_alignment.rs), analytic sensor workflow test, default/no_std example execution in [CI](../../.github/workflows/ci.yml). |
| ST-016 | Documentation must distinguish numeric/type contracts from calibration, proof, certification, and measured performance; no safety certification or timing guarantee is claimed. | Documentation review: [README](../../README.md), [safety notes](../SAFETY.md), [remaining work](../ROADMAP.md), and [qualified host performance evidence](../performance.md). This is a documented non-goal, not a passing numerical test. |
| ST-017 | apply_point, apply_vector and then are finite-checked by default under their existing names. Every participating non-finite input or computed result returns NonFinite. Successful arithmetic retains its evaluation order and finite bit patterns. Ignored entries remain ignored; finite scale/shear inputs are allowed without rigidity validation. | Implemented: per-entry NaN/Inf, point/vector/composition overflow, cancellation/subnormal/signed-zero, ignored-entry, non-rigid and different-intermediate regressions plus 1,024 affine bit-pattern samples in [checked_transform](../../tests/checked_transform.rs). |
| ST-018 | Point3<F,L:LengthUnit>, Transform<From,To,L:LengthUnit> and Vector3<F,U:Unit> have no default units. Point/translation/composition lengths match; inverse retains L. Dimensionless quaternion and generic vector mapping preserve U independently of translation L. | Implemented: typed analytic meter/foot workflow and opaque vector tests in [length_units](../../tests/length_units.rs); [point](../../tests/ui/point_length_mismatch.rs), [translation](../../tests/ui/translation_length_mismatch.rs), [composition](../../tests/ui/composition_length_mismatch.rs) and [arithmetic](../../tests/ui/length_arithmetic_mismatch.rs) compiler rejection, plus strict paired non-length point/transform/translation doctests in [point](../../src/point.rs) and [transform](../../src/transform.rs). |
| ST-019 | Explicit convert_to is available only for opt-in LinearLengthUnit lengths, shared by Quantity, Point3, length Vector3 and Transform. It preserves frames; transform scales translation only, retains linear bits and emits canonical bottom. No implicit conversion occurs. | Implemented: analytic foot definition/workflow and matrix-bit regressions in [length_units](../../tests/length_units.rs); paired success/compile-fail angle and Dimensionless rejection in [units](../../src/units.rs) and [vector](../../src/vector.rs) doctests. E0277 was reviewed; stable rustdoc checks rejection, not error code. |
| ST-020 | Conversion checks metadata before values: positive finite scales, then positive finite representable ratio, then finite inputs/output. InvalidUnitScale and UnrepresentableUnitConversion are distinct; NonFinite handles numeric failure. Finite same-unit components preserve bits; component underflow/rounding are allowed. | Implemented: invalid source/target metadata, ratio zero/infinity even for zero values, NaN/Inf/overflow/subnormal/signed-zero cases, 1,024 finite-bit samples and 1,024 bounded roundtrips in [length_units](../../tests/length_units.rs). Mixed tolerance 1e-11+32*EPSILON*abs(expected), values [-1e6,1e6]; no all-extreme-ratio/exact-roundtrip promise. |
| ST-021 | Custom unit markers are open/trusted; opt-in metadata cannot verify dimension, calibration or actual linearity. Raw constructors/public values can relabel numbers; matrix coefficients must be dimensionless for unit semantics. No marker value-trait bounds, general unit algebra, offset conversions or registry. | Qualified contract: bare custom length/velocity/opaque markers in [length_units](../../tests/length_units.rs); source review and [all unit decisions/limitations](../units.md). A dishonest custom LengthUnit declaration cannot be detected by type checking. |

The tests named in these files are the verification entry points. No generated
trace matrix or external compliance tooling is implied. Changes to a contract
must update this table and its concrete evidence in the same review.

The [borrowed-validation study](../borrowed_validation.md) provides experimental
lifetime/type/bit evidence without extending the production contracts above.
Its prepare-time matrix errors and fixture batch protocol are not approved APIs.
See [prototype tests](../../tests/borrowed_validation.rs) and
[live-borrow rejection](../../tests/ui/borrowed_matrix_mutation.rs).

## Separate Python binding contracts

These are runtime adapter contracts, not extensions of Rust compile-time proofs.

| ID | Python contract | Verification |
| --- | --- | --- |
| PY-001 | Frozen non-subclassable process-local frame identity, pointer equality/hash, closed immutable units; call-time frame/unit/kind checks, no implicit conversion. | identity/frozen/runtime checks and copy/pickle cases in [installed-wheel tests](../../python/tests/test_batches.py). |
| PY-002 | C-contiguous bare-native-d float64 (N,3)/flat3N input is snapshotted while attached, finite import enforced, external writers excluded. Rust-owned immutable data only while detached. | buffer shape/dtype/endian/stride/unaligned/zero and snapshot/alias tests; [adapter source](../../python/native/src/lib.rs). Concurrent foreign writers are an explicit unsupported condition, not a tested atomic-snapshot guarantee. |
| PY-003 | Checked core math and unit dispatch reused; all-or-nothing output, first ascending zero-based row error, metadata first, empty applications do not validate unused raw matrices. | 4,096 random-bit direct-core parity and all-position scope tests in [native kernels](../../python/native/src/kernels.rs); analytic workflow/error tests in installed wheel. |
| PY-004 | First view copies once into immutable cached bytes (plus zero fill); later flat views share bytes, survive batch deletion and cannot mutate the Vec. Viewed batches retain two payloads. | cached-base/lifetime/concurrent tests, [safe exporter](../../python/native/src/lib.rs), structural review and [RSS evidence](../python/2026-11-03/README.md). |
| PY-005 | Core remains normal-dependency-free/no_std; binding std/CPython, allocations/copies, closed-unit/runtime checks and platform limits are explicit. No native parity/zero-copy/certification claim. | separate manifests/locks, root graph gates, [guide](../PYTHON-GUIDE.md), [Python CI](../../.github/workflows/python.yml); compile/runtime results reported separately. |
| PY-006 | The repository lab example uses explicitly synthetic 100 Hz feet telemetry, shared runtime frame identities, explicit meter conversion and Rust batch mapping/inverse/vector operations. Independent oracle checks bounded coordinates; failures are actionable/all-or-nothing. | [Example](../../python/examples/lab_workflow.py), [all-sample oracle/outside-checkout CLI/error tests](../../python/tests/test_lab_workflow.py), [walkthrough and limits](../python_lab_workflow.md). |
